# 提案（役割①の出力）

毎時、役割①が書き手の体験・人が集まり残るか（集客/定着）の観点で 1 件書く。
新しいものを上に。役割②はここの最新を読んで設計する。
標準制約（決済を持たない・依存を増やさない・数字を競争にしない・
個人単位の行動計測をしない・検査/認証/上限を緩めない・第三者 JS を使わない）に
触れる提案は **要判断** と明記し、人が決めるまで役割②以降に流さない。

書式:

## <日時> <提案名>
- 状態: 未設計 / 設計済み / 実装済み / 要判断
- 何を: / なぜ: / 期待効果: / 根拠の事例: case-studies.md の番号

---

- 根拠の事例: case-studies.md の 14（site 側 case-studies 12 も参照） 一覧・個人ページに RSS を付ける（実装順③の設計材料）

  新着全体 1 本＋書き手ごと 1 本。GAMEYARD の実装（uploads/feed.xml、
  site 側 proposals 2026-08-08 11:15・実装済み）を流用する

  果たす役割（事例 13）を、アカウント不要・個人計測なしの RSS で置き換え
  られる。GAMEYARD で同型を実装済みなので設計コストも小さい

  数少ない読者を取りこぼさない。外部のまとめ・bot 経由の拡散面にもなる
- 根拠の事例: case-studies.md の 13（対比は 12） Story 投稿フォームにブラウザ側の自動保存（Story 設計の材料）
- 状態: 未設計（**Story 投稿（次の②が設計）の材料。単独では取らない**）
- 何を: Story 投稿フォームの入力を localStorage に自動保存し、ページを
  閉じても書きかけが残るようにする。サーバーへの下書き保存（SPEC の
  公開/下書き 2 択）とは別の、送信前のローカル控え。投稿完了時に消す

- 期待効果: 初投稿の完走率が上がる（撤退条件「Story 30 本」に直結）
- 根拠の事例: case-studies.md の 10（機能の線引きは 11 も参照） つまずきタグの語彙は自由入力＋正規化で始める
- 状態: 未設計（**待機。アカウント段階 C 完了までは②へ流さない**）
- 何を: つまずきタグ（SPEC 実装順④）の語彙運用を決めておく。
  (1) 事前定義リストを作らず自由入力で始める（小文字化・前後空白除去の

  （dev.to 型。最初は説明なしでよい）。(3) 1 Story あたりのタグ数上限は
  少なめに固定（例: 各軸 5 個。上限は後から緩めない決まりに従う）

- 期待効果: タグ実装が語彙設計で止まらない。検索流入の面が Story 数に
  比例して自然に増える
- 根拠の事例: case-studies.md の 8・9 文化を画面の文言にする（トップ・投稿フォームのコピー）
- 状態: 未設計（**待機。調停 15:50 の規則により、アカウント段階 C 完了までは
  ②へ流さない**）
- 何を: トップページと Story 投稿フォームの文言に、文化の 3 点を短く明示する。

  「AI を含む使ったツールを普通に書く」。デザイン変更ではなくコピーの追加
- なぜ: 「読まれなくていい」を明示することがサービスの売りになる実例がある

## 2026-08-08 14:12 JST Story の書式を「3 枠テンプレ＋つまずきの解決状態」にする
- 状態: 実装済み bce09ee（SPEC 追記分。フォーム・store は Story 実装の番で）
- 何を: Story 投稿の入力書式を、任意の 3 枠テンプレ
  「やったこと / つまずいたこと / 次の一歩」＋つまずきに「未解決 / 解決」の
  状態を持たせる形で SPEC に定める（テンプレは強制しない。自由文でも書ける）。
  実装順は SPEC どおり（①アカウント → ② Story 投稿）なので、
  今回の設計は **SPEC への書式追記**として行い、実装は②の番で適用する。
- なぜ: 書き手が最初に詰まるのは白紙（何を書けばいいか分からない）。
  Zenn のスクラップは「進行中・未解決でも気軽に残す」形式を記事と分けて
  成立させており（事例 2）、itch.io の devlog も頻繁な小さい更新が主体
  （事例 1）。「つまずき」を状態つきで持てば、SPEC のつまずきタグ（実装順④）
  の土台にもなる。
- 期待効果: 初投稿の敷居が下がり、Story が「完成報告」でなく「続けて書く
  記録」になる（定着）。未解決のつまずきは後から来る人の検索の入口になる。
- 根拠の事例: case-studies.md の 1・2（外部リンク型の裏付けは 3）
