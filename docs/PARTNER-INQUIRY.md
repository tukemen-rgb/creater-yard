# Creator Partner 相談ページ・問い合わせ導線仕様

2026-08-08 経営企画判断。初回売上を優先しつつ、未公開サービスで申込や
効果を過大に約束しないための最小仕様。

## 結論

初期導線は、契約を成立させる「申込フォーム」ではなく、
**Creator Partner の相談受付ページ**（`/partner`）とする。

- CTA は、社長が確定した単一の法人窓口へのメール
- サイト内DB、外部フォーム、第三者JavaScript、Analyticsは使わない
- 料金・開催日・契約条件が未確定の間は「申込」「購入」「契約」という
  表現を使わない
- Creator向けトップページには当面大きく掲出せず、営業資料から
  `/partner` へ直接案内する。Creator体験と法人営業を混在させない
- 最初の相談実績を見てからフォーム化を再判断する

## ページの役割

ページだけで契約を完結させず、次の3点を達成する。

1. 広告枠ではなくCreator支援への参加であると説明する
2. 提供できるもの・できないものを商談前に合意する
3. 必要情報を揃えた相談メールを起動する

## 表示内容

### 1. 一文で

> Creatorの制作と学びを、一緒に支える企業・団体を募集しています。

「スポンサー募集」や「広告掲載受付」は主見出しに使わない。

### 2. 初回に相談できる内容

販売開始ゲートが完了するまでは、**単発1企画の共同設計**だけを表示する。

- Creator Challenge
- Workshop

Learning Week、年間Partner、Recipe公式枠は将来候補としても販売CTAに
並べない。履行範囲を増やさないため。

### 3. 約束すること

- 共催表示は合意した企画ページ内に限定
- 報告は実測できた合計値のみ
- 未公開・立ち上げ期であることを明示
- 個人単位の行動データ、参加者の連絡先、第三者計測タグは提供しない
- 順位づけや検索結果の優遇はしない

### 4. 相談時に必要な情報

メール本文テンプレートに次だけを入れる。

- 企業・団体名
- 担当者名
- 返信先
- 関心のある支援（Challenge / Workshop / 相談して決めたい）
- Creatorに届けたい価値
- 希望時期
- 補足（任意）

予算、住所、請求情報、ロゴ、添付ファイルは初回相談で収集しない。
契約前に不要な情報を持たないため。

### 5. CTA

- 主CTA: 「Creator Partnerについて相談する」
- メール件名: `Creator Partner相談｜{企業・団体名}`
- メールクライアントが開けない場合に備え、確定した窓口アドレスを
  コピー可能なテキストでも表示
- 問い合わせ先が未設定の場合、CTAを表示せず「相談窓口準備中」とする。
  空アドレスや仮アドレスへ送信させない

## 実装条件

- 窓口は環境変数 `NEXT_PUBLIC_PARTNER_CONTACT` で設定する案とする。
  メールアドレスは公開情報だが、環境ごとの誤送信を避けるためコードへ
  直書きしない
- 値はメールアドレス形式だけを許可し、改行を拒否する
- `mailto:` の件名・本文は `encodeURIComponent` 相当でエンコードする
- ファイルアップロード、自由なHTML、外部埋め込みを入れない
- 個人情報の利用目的（相談への返信・商談管理）と保存方針をページから
  確認できる状態にしてから公開する
- 返信は**3営業日以内を内部目標**とし、対外的な保証表現にはしない
- 自動返信は初期には実装しない

## 運用

1. 相談受信
2. 営業対象・支援内容・ブランド適合性を確認
3. 3営業日以内を目標に返信
4. 条件整理後に見積・契約へ進む
5. 問い合わせ件数等は個人情報を含まない合計値だけを月次集計

顧客名、担当者名、メールアドレス、相談本文をGitHub Issueや公開リポジトリへ
記録しない。

## 検証

公開前に以下を確認する。

- [ ] 窓口未設定時に送信CTAが表示されない
- [ ] 設定時に正しい宛先・件名・本文でメールが起動する
- [ ] 日本語・記号を含む件名と本文が壊れない
- [ ] モバイルとPCで窓口アドレスをコピーできる
- [ ] 料金、効果、人数、開催日を未確定のまま約束していない
- [ ] 個人データ提供不可・第三者計測不可を表示している
- [ ] 外部JavaScript、Analytics、外部フォームを読み込んでいない
- [ ] 利用目的と保存方針への導線がある

## 実装前に社長が確定する事項

- 公開する法人窓口メールアドレス
- 個人情報の保存方針・削除時期
- 初回商品をCreator ChallengeとWorkshopのどちらに絞るか
- 外部営業とページ公開の開始
