# Creator Partner 共催表示の本番仕様

2026-08-08 経営企画判断。「スポンサー枠」をサイト全体へ常設せず、
Creator支援が実際に行われた企画の文脈内だけで表示するための最小仕様。

## 結論

CreatorYardでは、広告バナーやサイト共通のスポンサー枠を作らない。

本番表示は、実在するPartnerと合意済みの企画に限り、
**「この企画は {Partner名} と一緒に開催しています」**という共催・協力表示に
統一する。Partnerが未決定の間は、空枠、募集中枠、ダミー企業、仮ロゴを
公開しない。

## 表示する場所

初回は次の2か所だけとする。

1. **対象イベントの告知・詳細ページ**
   - ページ冒頭の企画説明直後
   - Partner名、役割、ロゴ、支援内容をまとめた1ブロック
2. **終了後のイベント記録ページ**
   - 「協力・共催」の履歴として残す
   - 開催終了後は販売CTAや期間限定の提供案内を外し、支援事実だけを残す

最初の契約が成立するまで `/partners` 一覧ページは作らない。
空のPartnerページはユーザーにも企業にも実績があるような誤解を与えるため。

## 表示しない場所

- サイト共通ヘッダー・フッター
- Creator Storyの本文・カード・一覧
- 検索結果・タグ一覧
- アカウント登録・ログイン画面
- Creator個人ページ
- 通知、モーダル、追従バナー
- ランキング、優先表示、検索順位への反映

金額によってStoryやCreatorの並び順を変えない。

## 表示ブロック

### 必須項目

- 関係表示: `Creator Partner` と `共催` / `協力` / `提供` のうち実態に合うもの
- Partnerの正式な表示名
- 何を支援したか（例: 講師、教材、参加者向けライセンス、開催費）
- ロゴ（掲載許可を確認した自前配信画像）
- Partner公式サイトへのリンク
- 対象企画名
- 表示開始日・終了日
- 終了後に記録として残す範囲

金銭・物品・役務の提供がある場合、その関係が利用者に分かる表現を省略しない。
「おすすめ」「公式認定」など、CreatorYardが製品品質を保証したと受け取れる
表現は使わない。

### 任意項目

- PartnerからCreatorへの短いメッセージ
- 提供物の利用条件へのリンク

Partnerによる自由なHTML、JavaScript、計測タグ、埋め込み、フォームは許可しない。

## 技術条件

- 初回はイベントページ内の静的データで実装し、Partner管理画面を作らない
- ロゴは取得元からホットリンクせず、許可済みファイルを自前オリジンで配信
- ロゴには代替テキストと寸法を設定し、レイアウトずれを防ぐ
- 外部リンクは通常リンクのみ。第三者JavaScript、トラッキングピクセル、
  外部Analyticsを読み込まない
- Partner提供のURL、表示名、説明文は運営が確認し、そのままHTMLとして
  解釈しない
- 表示開始前、変更時、終了時に手動レビューを行う
- Partner別・Creator別の閲覧履歴を保存しない

## 本番反映ゲート

次をすべて満たすまで本番表示しない。

- [ ] 実在するPartnerと対象企画が確定
- [ ] 契約・請求・入金または合意した開始条件を確認
- [ ] 表示名、ロゴ、リンク、支援内容について掲載許可を確認
- [ ] 関係表示（共催・協力・提供）が実態と一致
- [ ] 表示期間と終了後に残す範囲を合意
- [ ] リンク先と提供条件を運営が確認
- [ ] ダミー値・未確定値・推測の成果数がない
- [ ] モバイル／PCで表示を確認
- [ ] 外部スクリプト・外部計測がない
- [ ] 終了時の更新担当と期限が決まっている

## 終了時の扱い

- 開催終了日までに期間限定CTA、クーポン、応募リンクを停止
- イベント記録にはPartner名、役割、実際に行われた支援内容だけを残す
- 契約で削除期限が定められている場合はその条件を優先
- 実施されなかった支援内容や未確認の成果を記録に残さない

## 成果確認

本番表示の完了条件は露出数ではなく、以下の事実で判定する。

- 対象イベントページに合意どおり表示された
- 誤リンク・期限切れ表示がない
- 外部計測や個人データ提供がない
- 終了処理が期限内に行われた
- 報告対象の合計値は、実際に計測できたものだけである

表示回数、クリック数、参加者数は実装・実測できるまで販売資料で約束しない。

## 社長判断事項

- Partnerとの契約、請求、入金確認
- 正式な表示名・ロゴ・リンク・支援内容の最終承認
- 表示開始・終了の本番操作
- 関係表示について必要な法務確認
- 契約終了後も共催記録を残す期間
